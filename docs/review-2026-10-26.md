# 整体优化审查（2026-10-26）

作者在单击进大图之后问"整体再看一下 APP 还有没有什么可以优化的地方"。三路只读审查（Android 界面、Rust 核心、macOS 前端）并行完成，重点条目逐条抽查过代码。每条：位置、问题、改法、收益。做完一条就在这里打勾。

真机实测（小米 25128PNA1C，当前包）：冷启动 114 ms；空闲 PSS 105 MB；安装包 84 MB（解压 225 MB，其中 QNN 库 200 MB：`libQnnHtpPrepare.so` 84 MB 只有第一次编译 NPU 图用，六代 HTP 的 Skel 各 9–17 MB、一台手机只用一份）。

## 优先做（跨端、真 bug 或体验硬伤）

### Android

1. [x] **SAF 权限失效会把镜像整个清空**（`core/Media.kt:126-160`）。`TreeDocumentFile.listFiles()` 在权限被收回、网盘离线时吞异常返回空数组 → `keep` 为空 → `walkBottomUp().delete()` 把镜像里每一张照片删掉。改法：同步前核对 `persistedUriPermissions`；`found` 为空而镜像非空时当作列举失败、跳过删除；界面给"重新授权"。收益高（避免静默丢数据）。
2. [x] **大图查看器 4096² 解码 × 三页**（`ui/project/Viewer.kt:420/220/333`）。一张 64 MB，三页近 190 MB，还把 480px 墙缩略图挤出 Coil 缓存，退回墙上要重解。改法：解码边长 = 屏幕长边 × 2 封顶 4096；该请求不进内存缓存；非当前页置空 large/sharp。收益高。
3. [x] **大图缩放每帧重组、手势检测器每帧重启**（`Viewer.kt:205/334/355/442`）。`pointerInput(scale)` 以 Float 为 key；组合层读 `Animatable.value`。改法：key 改布尔；detail 触发改 `snapshotFlow` + debounce；小地图条件用 `derivedStateOf`。收益高（缩放掉帧主因）。
4. [x] **照片墙捏合插值用过期的 items / width / layout**（`ui/project/Wall.kt:254` `pointerInput(Unit)`）。换筛选、切网格↔瀑布、旋转后再捏，目标布局按旧数据算。改法：`pointerInput(items, width, layout)` 或 `rememberUpdatedState`。收益高。
5. [x] **`CullState.coords` 只增不减**（`Culling.kt:144/157`，写入点 `Culling.kt:385`、`Scanning.kt:109/121`、`Single.kt:158`、`Compare.kt:267`）。持有每个滚过的格子的 LayoutNode；`Session.results/stages/live` 换项目也不清。改法：`DisposableEffect` 里 remove；`Session.enter()` 清三个表。收益中高。
6. [x] **对比页缩放每帧重组整个 CompareView；人物筛选下每帧重算 groupBy**（`Compare.kt:190/303/317/124`，`Culling.kt:366` 的 `filter` 没 remember）。改法：`view` 只在 `graphicsLayer` 里读；过滤包进 `remember`。收益中高。
7. [x] **`stopScan()` 阻塞调用落在主线程**（`Session.kt:314` → `callBlocking`；调用方 `ProjectScreen.kt:145`、`AnalysisService.kt:36`、`Scans.kt:29-45` 温度 / 电量回调）。改法：`scope.launch`。收益中（消除一类 ANR）。

### Rust 核心

8. [x] **Android 分析解码走三段路**（`analyze.rs:361-381`、`apps/android/rust/src/lib.rs:72-92` 没实现 `SystemImages::decode`，`core/Images.kt:43-51`）。每张：Kotlin 解码 → 缩放 → 压 JPEG 写盘 → Rust 再解 JPEG → 删文件。改法：`ImageHelper.decode(path, max) -> RGB 像素`，Rust 端 `RgbImage::from_raw`。收益高（估 20–40 ms/张，少写 flash）。
9. [x] **Android 上 HEIC / AVIF 的大图预览按 `max = 30000` 整张解码**（`analyze.rs:316`；`Images.kt:46-48` 的 `sampleFor` 变成 1；`Large.kt:36` 还会预取几张）。48 MP HEIC 约 190 MB 位图，极易 OOM，`large/` 很快撑满。改法：非原生格式也用 2560，或 `SystemImages::preview_max()` 按平台给。收益高。
10. [x] **分析缓存每次整文件重写 + fsync，且在 `cache` 锁内**（`cache.rs:275-288`、`engine.rs:680-689/733-748/1061-1081`）。万张项目每分钟重写几百 MB JSON，期间所有 `with_cache` 排队；转一张照片也全量重写。改法：追加式日志 / 分片；至少序列化移出锁。收益高。
11. [x] **MediaPipe 眼睛模型被加载两份、人脸流水线每次分析重新加载**（`engine.rs:564/662/783/812`、`facepipe.rs:133-137`）。改法：`Factory` 缓存 `Arc<FacePipeline>`；一次 `scan_project` 只 `start_vision` 一次。收益高。
12. [x] **分析失败的照片被静默丢弃**（`engine.rs:749` `eprintln!("skip")`，核心共 16 处 `eprintln!`，Android 的 stderr 没人看）。界面上照片就"消失"。改法：统一 `platform::log` + `emit("scan-skip", {path, error})`。收益高（可诊断）。

### macOS

13. [x] **分析期间整页只能看**（`Culling.tsx:918` `interactive={phase === "done" && …}`，搜索 / 视图 / 整理 / 设置按钮都 disabled）。几千张要跑几十分钟，已判定的既不能选也不能改判。改法：有 `photo` 的格子分析中也可交互，`decide` 对 `live` 生效，只把整理留到结束。收益高。
14. [x] **分析中每帧重排整面墙**（`Culling.tsx:481-491` `items` 依赖 `tick`，`Wall.tsx:131` 每帧重跑 `place()`）。改法：静态部分（key / ratio）和动态部分（photo / stage）拆开。收益高。
15. [x] **每个 Tile 开 motion `layout="position"`**（`Tile.tsx:85`），位置本来由绝对定位给出，每帧上百次强制布局读取。改法：去掉 layout 或只在 done 后开。收益高中。
16. [x] **墙上没有上下键和多选**（`Culling.tsx:580-601`），连拍 20 张只能一张张点。改法：`rowNeighbour`，shift 范围 / ⌘ 追加，`decide` 接受数组。收益高。
17. [x] **Viewer 快捷键闭包过期（两个真 bug）**（`Viewer.tsx:348-369` 依赖漏 `help`、`active`）：帮助气泡开着按 Esc 直接关查看器；进设置页在输入框敲 p/r/x 仍改判。收益中。

## 第二轮：上一轮没覆盖的流程（2026-10-26 晚）

优先批 17 条合入后，作者问"还有没有其他可以优化的"。这一轮只看首次打开、模型下载、NAS 与备份、喜好学习、整理、后台与发布。第 1、2、3、5、6、9、17 条抽查过代码，属实。`A/` 指 `apps/android/app/src/main/java/com/fleetinggleam/android/`。

### 会丢数据或卡死（先做）

18. [x] **网盘回收"复制再删"可能丢原图**（`A/core/Organize.kt:107-111`）：输入或输出流为 null 时一个字节没复制，`doc.delete()` 照样执行并算成功。改法：核对写入字节数等于源大小再删，否则删掉空的回收文件、算失败。
19. [x] **"重置已学习的偏好"和风格重置一点就清、没有确认**（`A/ui/settings/SettingsScreen.kt:269`、`apps/desktop/src/…/Settings.tsx:112-113/399`、`Styles.tsx:182`、`A/ui/settings/StylesScreen.kt:161`）。改法：和删除风格同样的确认框，写明"N 次判断、M 张参考"，或重置前自动导出一份。
20. [x] **Android 后台下载时再触发另一个模型包，等待方永远卡住**（`A/core/Models.kt:76-86` 直接覆盖 `_gate`，`:142` 前一个完成时清掉新的；核心同时只允许一个下载）。改法：排队；下载中设置页按钮置灰。
21. [x] **导入别的设备的喜好后本机学习可能静默失效**（`packages/core/src/prefs.rs:200-204` 训练取出现最多的维度，`:151` 维度不一致时 `predict` 返回 None）。改法：固定用当前分析模型的维度，别的维度样本保留但不参与训练，设置里说明。
22. [x] **Android 15 起前台服务 6 小时上限没处理**（`A/service/AnalysisService.kt:42/47`，全仓无 `onTimeout`）：超时不 `stopSelf` 会被系统判崩溃。改法：覆写 `onTimeout`，暂停并通知"已分析 n 张，打开应用继续"。

### 第一次用就会碰到

23. [x] **Mac 没把系统代理交给核心**（`apps/desktop/src-tauri/src/lib.rs` 无 `set_proxy`，Android 有）：开着系统代理的用户第一次下模型就失败，只说"请检查网络"。改法：启动时读系统 HTTPS 代理交给 `set_proxy`；设置里可手填。
24. [x] **下载取消一次，档位就被锁死**（`apps/desktop/src/strategy.ts:39-43`、`A/core/Strategy.kt:40-44` 在下载前就写入 tier）。改法：下载成功后再写；询问框给"先用标准模型"。顺带：standard 包同时下 fp16 和 int8 两份（`modelpacks.rs:23`，265 MB），一台设备只用一份；Android 示例照片一点就要下几百 MB；Mac 起始屏没有示例照片入口。
25. [x] **模型下载没有断点续传、不自动重试**（`packages/core/src/modelpacks.rs:130` 每次截断 `.part`，`:151-153` 出错即删）：857 MB 下到 800 MB 断一下就从 0 重来。改法：保留 `.part`，`Range` 续传，退避重试 3 次，校验失败才删。
26. [x] **下载前不看网络类型和剩余空间，错误不分类**（全仓无 `metered` / `StatFs`）：移动数据静默下 600 MB；磁盘满或校验失败也说"检查网络"。改法：按流量计费提示、总大小 × 1.1 对比可用空间、网络 / 校验 / 空间三类中文说明。
27. [x] **Mac 下载模型时对话框锁住整个应用**（`apps/desktop/src/…/ModelGate.tsx:13`）。改法：和 Android 一样可以"后台下载"，侧栏显示进度。

### 长时间分析

28. [x] **Mac 分析期间不阻止系统睡眠**（`src-tauri` 无 `beginActivity` / IOPM）：走开后空闲睡眠，分析停住；被遮挡时 App Nap 降速。改法：分析期间 `NSProcessInfo.beginActivity(.userInitiated | .idleSystemSleepDisabled)`。
29. [x] **Android 过热 / 低电暂停时撤掉前台服务，后台续不上**（`A/core/Scans.kt:71/75-79`）：系统拒绝从后台启前台服务，异常被吞。改法：暂停期间保留前台服务，通知写"手机太热，已暂停（n/N）"。

### NAS 与网盘

30. [x] **NAS 离线时已分析过的项目整个打不开**（`A/core/Session.kt:213`、`apps/desktop/src/modules/Culling.tsx:302`、`packages/core/src/engine.rs:521`）。改法：离线跳过同步，用镜像只读打开，提示"显示上次同步的照片"，NAS 整理操作置灰。
31. [x] **NAS / 网盘镜像不计入缓存、从不清理**（`engine.rs:2150-2160` 只管缩略图；彻底删除项目不删 `nas/<id>/`、`files/saf/<id>`）：设置显示 200 MB，实际几十 GB。改法：设置单列"NAS / 网盘副本"大小，可按项目清；彻底删除项目时删掉它独占的镜像。（即 ROADMAP A3 未做项）
32. [x] **群晖 / 威联通的回收站与快照被当成照片；单个目录没权限整次同步失败**（`packages/core/src/files.rs:9-11` 的 `is_junk`、`nas.rs:438/488` 用 `?` 中止、`:284` 把 AccessDenied 说成密码错误）。改法：`#recycle`、`#snapshot`、`@Recycle`、`@Recently-Snapshot` 加进 `is_junk`；没权限的跳过并记日志。
33. [x] **NAS 密码错误被说成"连不上"**（`engine.rs:1408-1418` 丢掉连接错误）。改法：返回最后一次错误，界面分开说"密码不对 → 去设置"和"连不上 → 重试"。

### 其他

34. [x] **恢复自己的备份会把本机判断重复一份**（`packages/core/src/taste.rs:94-100/132-137` 只和 `imported` 去重）。改法：带来源设备 id 或向量哈希，本机判断优先。
35. [x] **导出不能取消；磁盘满时留下截断文件、只说"跳过 N 张"；重复导出整份再复制**（`engine.rs:1448-1458`、`files.rs:144-153`）。改法：导出前查空间、失败删目标并列原因、加取消、同名同大小同时间视为已导出。
36. [x] **没有任何本地崩溃记录**（无 panic hook、`UncaughtExceptionHandler`、`ApplicationExitInfo`）。改法：核心与 Kotlin 崩溃写进 `data/logs/crash-*.txt`；关于页"导出诊断信息"，生成本地文件、用户自己决定发不发。
37.
