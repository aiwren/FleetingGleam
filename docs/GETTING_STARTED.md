# 新手上手指南

这份指南带你从安装开始，走完一次完整的选片：导入照片、让它分析、查看结果、做决定、整理文件。第一次用大约 10 分钟（不含模型下载时间）。

## 开始之前

- 需要 **macOS 15 及以上**。Windows 版本还在计划中。
- 分析全部在你自己的电脑上运行，**照片不会上传**。
- 应用本身不带分析用的模型（它们体积很大），而是在你**第一次用到某项功能时才下载**，下载完之后就完全离线。所以第一次使用需要联网。

## 1. 安装

1. 打开 [Releases](https://github.com/lcopilot/FleetingGleam/releases)，下载最新版本的 `.dmg`：Apple Silicon（M1、M2……）选带 `aarch64` 的，Intel 芯片选带 `x64` 的。不确定的话，点屏幕左上角  → 关于本机，看“芯片”一栏。
2. 打开 `.dmg`，把 FleetingGleam 拖进“应用程序”。
3. **第一次打开可能被系统拦住**（如果这个版本还没有经过苹果签名）。这时打开「系统设置 → 隐私与安全性」，滚到最下面，找到被拦住的提示，点“仍要打开”。只需要做一次。

## 第一次使用：先下载模型

模型是应用“看懂照片”的部分：评估清晰度、曝光和观感，识别场景，用文字搜索照片等。它们不放在安装包里，原因很简单：太大了。

1. 新建一个项目，选一个放着照片的文件夹，点“开始分析”。
2. 应用会弹出一个对话框，写明**要下载什么、有多大**，例如“第一次分析照片前，需要先下载分析模型（约 xxx MB）”。
3. 点“下载”。下载过程中能看到进度，随时可以取消；网络不好失败了，点“重试”即可。
4. 下载完就开始分析了。之后再分析，不会再下载。

不同功能用不同的模型包，**用到才会问你，没用到就不会下载**：

| 模型包 | 什么时候会让你下载 |
|---|---|
| 标准分析 | 第一次分析照片。日常够用，速度快 |
| 高质量分析 | 在设置里把分析质量切到“高质量”。更准，对模糊、构图和观感更敏感 |
| 极致分析（实验） | 切到“极致”。最新一代的美学评分，体积最大、更慢 |
| 照片搜索 | 第一次开启“用文字搜索照片”，之后会在后台为照片建立索引 |
| MediaPipe 眼睛检测 | 在设置里把闭眼检测切到 MediaPipe |
| 人物识别 | 第一次用“把不同的人分开” |
| 场景描述 | 内置词库认不出某个场景，想让模型自己写一句描述时 |

已经下载的模型可以在「设置 → 数据 → 已下载的模型」里查看大小，不用的可以删掉，下次需要时会再问你。

## 2. 导入照片

- 点“新建项目”，选择一个或多个文件夹。一个项目就是一组文件夹，加上你对这些照片的取舍。
- 项目会一直保留在“项目”页，下次打开接着用。删除项目不会删除你的照片文件，项目会先进回收站，保留 7 天。

## 3. 等它分析

分析开始后：

- **缩略图会先出现**，评分在后台一张张补上，不用等全部完成才能看。
- 同一瞬间的连拍会**自动排在一起**，作为一组。

## 4. 看懂结果

每张照片会落在三类里：

| 标记 | 含义 |
|---|---|
| 金色星标（实心） | **保留**：应用建议留下的，通常是每组里最好的一张 |
| 空心星标 | **待定**：值得再看一眼 |
| ✕ | **淘汰**：这一组里有明显更好的，这张会变小、变浅，但不会变黑白 |

点开一张照片，右侧的**检查器**会告诉你理由：总分，以及清晰度、曝光、AI 观感等逐项得分，还会提示“同组里有更好的一张（76 对 61）”。

> 评分只是参考。它目前用的是手工调的常数，还没有用大量人工标注校准，所以会出错。比如一张“闭着眼睛睡着的孩子”，在技术上并不完美，却可能是你最想留的一张。**最后的决定权在你。**

## 5. 对比并做决定

- 进入对比视图，把同一组的几张放大并排比较，滚轮缩放、拖动平移，两张的缩放是同步的。
- 用键盘快速决定：

| 按键 | 作用 |
|---|---|
| `P` | 保留 |
| `R` | 待定 |
| `X` | 淘汰 |
| `⌘Z` | 撤销上一步 |
| ← → | 上一张 / 下一张 |
| 空格 | 放大查看 |

- 你手动改过的决定，会优先于应用的建议。

## 6. 整理文件

做完决定后，点“整理”：

- 保留的照片会被移到一个新文件夹；
- 其余的会被放进**废纸篓**，不会被直接删除，随时可以从废纸篓里恢复。

整理会移动真实的文件，所以**重要的照片请先备份**。

## 更多功能

- **用文字搜索照片**：在「设置 → 照片搜索」里开启，需要先下载搜索模型。之后可以输入“烟花”“两个人”“雨伞”这样的描述，中英文都行。
- **学习我的喜好**：在「设置 → 个性化」里开启。你每次手动保留或淘汰，应用都会在本机学习你的偏好；也可以指向一个你以前挑好的文件夹，让它一次学会。打开“启用自定义风格”后，可以为婚礼、街拍分别建立不同的风格，每个项目选用一种。
- **分析质量与分析方式**：在「设置 → 性能」里调整。一般保持默认就好。
- **闭眼检测**：在「设置 → 性能」里选用系统自带的 Vision，或者 MediaPipe。

## 常见问题

**下载模型失败了怎么办？** 检查网络后点“重试”。如果一直失败，可能是模型服务器暂时不可用，稍后再试。

**能完全离线用吗？** 模型下载完之后可以。第一次需要联网下载模型。

**我的照片会被上传吗？** 不会。应用只会联网下载模型文件，不会发送你的照片或任何照片信息。

**打不开，提示“无法验证开发者”？** 见上面“安装”的第 3 步。

**想反馈问题或提建议？** 欢迎到 [Issues](https://github.com/lcopilot/FleetingGleam/issues) 告诉我们。
