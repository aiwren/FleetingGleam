# 选片工具竞品调研：咔咔选 KakaPick 与 LensLink（2026-11-02）

来源：两篇小红书笔记及其全部评论（分别 11 条与 114 条）、笔记配图里的界面截图。两款都是个人开发者的开源 / 免费工具，和我们一样主打"本地处理、不上传"。本文回答三个问题：它们做了什么、用户在评论里要什么、哪些界面和交互值得搬到我们这里。我们的产品要同时服务专业摄影师和普通用户，所以最后一节按这两类人分开给建议。

## 1. 两款产品一句话

| | 咔咔选 KakaPick | LensLink |
|---|---|---|
| 形态 | Mac 客户端，深色界面，橙色主色 | 跨平台（Windows / Mac），浅色界面，WebView 壳，宣传"只有 3 MB" |
| 核心主张 | "拍得多，也能选得快"：连拍自动成组 → 三张并排比 → 键盘打分 → 写回 Lightroom | "极速选片"：RAW + JPG 配对、秒级预览、键盘精选 / 删除、批量清理 |
| 技术 | 未公开；评论说"Vibe Coding"出来的 | LibRaw 解 RAW，Tauri / WebView |
| 分发 | 进群试用，未公开下载 | GitHub Releases，全平台 |
| 热度 | 11 条评论，多是求下载 | 314 赞、432 收藏、114 条评论 |

## 3. 用户在评论里说了什么

LensLink 的 114 条评论是真实需求清单，按出现次数归纳：

1. **要 1–5 星评级并能像 Bridge 那样筛选**（多人追问，10 月还有人问"现在有星级了吗"）。
2. **RAW 和 JPG 要联动**：Bridge 做不到评分联动；松下用户抱怨导出只出了 JPG。
3. **性能**：500 张 80 MB 的 RAW 导入直接无响应；"raw 加载半个多小时打不开"；WebView 占几百 MB 内存。
4. **格式**：CR3、新款尼康 NEF 打不开。
5. **Mac 首次打开提示"已损坏"**（未签名），要用终端去隔离属性。
6. **误删找不回**：移动硬盘上删除不进回收站。
7. **界面遮挡**：底部选图栏、旋转缩放的浮框挡住照片，希望能调透明度或隐藏。
8. **淘汰动画希望能关**，删得多了嫌卡。
9. **快捷键**：P 要右手离开方向键，希望全放左手；作者说可以切换。
10. **想要 AI 做闭眼 / 曝光检测、连拍废片筛选、相似照片对比**——这三样我们都有。
11. 跑题的需求：按"调调"把照片归类做作品集；把修片也一起干了。

KakaPick 的评论几乎全是"哪里下载"，说明需求是真的，但它没有公开分发。

## 4. 界面与交互里值得借鉴的地方

### KakaPick（深色、信息密度高、键盘优先）

- **组卡片带进度**：每个组一张卡，封面是组内几张的拼贴，下面一行"N 张 · 已评分 x · 入选 y"，再一条进度条；标题栏常驻"第 8 / 827 组 (1%) · 758 张已评分"。摄影师一眼知道干到哪了。我们的墙按分组排列但没有"每组处理进度"和"全局进度"。
- **三张并排 + 同步放大 + 底部缩略条**：对比视图固定三格，文件名、"RAW + JPEG"角标和星级一行放在每格底部；底部一排带序号的缩略图切换组内其它照片。我们的对比是两张起、按组，没有同步放大。
- **键盘提示常驻在底部**：一行小字"← → 浏览 · Z 淘汰/恢复 · X 保留 · 2–5 高分 · Space 前进/放大"。我们的提示要靠"提示：…"横幅和 ⌘ 提示。
- **首次使用的按键浮层**：半透明大卡片"KEEP X / REJECT Z / RATE 1–5"盖在照片上教一次。
- **评分后自动前进**："一套动作顺着做完，不打断判断"。我们按 P / X 后焦点不动。
- **交付前预览 + 一次回滚**："先预览，再确认；最近一次可回滚"。
- **首页"最近打开"卡**：项目名、"4305 张 · 758 已评分"、"5 分钟前"；旁边"体验示例相册"和"或手动输入路径…"；页脚一句"不上传照片 · 不改 RAW · 仅本机"。
- **筛选只有"全部 / 待处理"两档**：比复杂筛选面板更贴合"把没处理的做完"这个目标。

### LensLink（浅色、单窗口、工作台式）

- **顶部筛选标签**："全部 / 精选 / 待删除 / 未标记 / 单独文件"，其中"单独文件"（缺配对的）是我们没有的维度。
- **右侧 EXIF 卡片**：快门 / 光圈 / ISO / 焦距四格，下面机身、镜头、时间，再是"包含文件"列出 JPG 与 RAW 及各自大小，顶部一个 "JPG ONLY" 角标。
- **快速分类按钮右侧直接标快捷键**：精选 [P]、取消标记 [U]、删除 [X]，按钮本身就是说明书。
- **工具栏上的危险操作带计数**："确认删除 0 项 / 删 RAW (0) / 删 JPG (1) / 导出精选"，动手前就知道会动几个文件。
- **底部状态行**："3 总计 · 0 已精选 · 0 待删除 · 1 单独文件"。
- 它的问题（也是教训）：浮层挡图、动画不能关、大 RAW 卡死、WebView 内存。

## 5. 建议纳入我们产品的内容

原则：**普通用户看不到专业功能，专业功能在有 RAW 或打开"专业"开关时才出现**；深色 / 浅色、琥珀只给"保留"等规则不变。

### 5.1 功能（专业摄影师）

1. **RAW + JPG 配对**：同名文件视为一张，打分一次，保留 / 淘汰一起动；导出可选"JPG / RAW / 都要"；筛选加"缺配对"；检查器显示"包含文件"。共用一套"找配对"逻辑。
2. **写回 Lightroom / Bridge**：整理菜单加"写入评分与标记"，RAW 写 XMP 旁车文件，JPG 写进文件；内容为星级、精选 / 拒绝、颜色标签；执行前列出将写入的文件数，可回滚最近一次。
3. **手动 1–5 星**：数字键 1–5 打星、0 清除，筛选面板按星筛，随第 2 条写回。普通用户把它当"特别喜欢"。
4. **快捷键预设 + 自定义**：默认（P / R / X）和左手（Z 保留 / C 待定 / X 淘汰），再允许逐个改。
5. **完整 EXIF 面板**：检查器里补快门 / 光圈 / ISO / 焦距 / 机身 / 镜头四格卡。

### 5.2 交互（两类用户都受益）

6. **处理进度可见**：标题栏"已处理 x / N"，分组卡角标"3 张 · 1 已决定"，筛选加"未处理"一档。
7. **决定后自动前进**（可在设置关）：按 P / R / X 后焦点跳到组内下一张；一组做完跳下一组。
8. **按键提示常驻**：对比视图和单张视图底部一行小字，首次进入时用一次性浮层教学替代现在的横幅。
9. **对比视图同步放大**：对比里按住或滚轮，几张一起放大同一区域（我们的放大细节已有切片，缺"同步"）。
10. **危险操作带计数与回滚**：整理菜单上直接显示"淘汰 12 张到废纸篓"，执行后给"撤销最近一次整理"。
11. **首页"最近项目"卡加统计和时间**："395 张 · 已处理 120 · 2 小时前"。
12. **舒适度设置**：淘汰动画可关；浮层（检查器、缩略条）可淡化或隐藏。

### 5.3 性能（评论里被骂得最狠的地方）

13. **大 RAW 秒开**：先用 RAW 内嵌的 JPEG 预览撑起墙和查看器，完整解码放后台替换。我们"打开项目慢"那条路继续走完。

## 6. 不建议采纳

- "3 MB 小体积"作为卖点：本地模型是我们的核心价值，体积做不到也不该比。
- 按"调调"自动归类作品集：场景分组 + 文字搜索已覆盖大半，单独做收益低。
- KakaPick 的"进群试用"式分发。

## 7. 对我们发布的提醒

- 未签名的 Mac 应用会提示"已损坏"，LensLink 评论里反复出现；公证要在公开前做完（路线图 A5）。
- 移动硬盘上的删除要明确提示"此处没有废纸篓"，我们对网络卷已经走回收文件夹，外置盘要确认同样处理。
- 大文件夹导入必须有进度与可取消，不能像 LensLink 那样无响应。

## 8. 建议落地顺序

1. RAW + JPG 配对 + 写回 XMP（共用配对逻辑，专业用户的核心诉求）。
2. 手动星级 + 快捷键预设（前端为主，一周内）。
3. 进度可见 + 自动前进 + 按键提示常驻（交互打磨，一起做）。
4. 大 RAW 秒开（性能）。
5. EXIF 面板、舒适度设置、整理回滚（零散小项）。
