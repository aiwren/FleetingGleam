怎么看这份清单：

- 每条一个编号（`A` = Android，`M` = macOS，`R` = 两端共用的规则），前面是复选框，勾选即表示要做。

## 0. 总的判断

三类问题里，**最伤"高级感"的是装饰和节奏，而不是层次**。两端的层次结构（页签、照片墙、检查器、分组列表）已经立得住，但上面叠了太多"会动的东西"和"会说话的东西"：

1. **同一件事发出好几个信号。** 保留一张照片，格子上同时有金星、琥珀描边、两圈光晕、星的光晕、一道横扫的光；分析中一个格子同时有扫光、呼吸边、进度环、阶段名、文件名、模糊渐清。每个单独看都讲得通，叠在一起就是作者说的"乱"。
2. **琥珀和四角星被借去表达别的意思。** 规范说琥珀只给"保留"，但进度条、筛选提示点、"允许后台"链接、对比视图里的"最佳"数值、单张小图条的指示灯、首页卡片的进度都在用琥珀；四角星既是"保留"的记号，又被拿来打五星评分、标"推荐"。意义一旦混，记号就不再是记号。
3. **节奏没有统一。** 两端各有一套动效 token（160 / 320 / 600 / 900 ms 和四种弹簧），但实际用到的时长有十几种（140、200、260、300、500、620、700、750、760、950、1100 ms……），弹簧阻尼从 0.39 到 0.997 都有。"不弹跳"写在规范里，星星却以阻尼 0.39 弹出来。
4. **常驻的说明句。** 准备页底部三行解释、首页副标题、大图底部的快捷键提示、对比视图的操作提示、侧栏"即将推出"的占位模块——这些句子第一次有用，之后都是噪音。
5. **数字重复。** 桌面端分析中，已分析 / 总数同时出现在顶栏、横幅、筛选栏三处；保留 / 待复查 / 淘汰在横幅和筛选栏各一次。

做的顺序建议：先定第 1 节的规则（R1–R12），再按屏改。规则定了，很多屏的条目会自然消失。

## 1. 两端共用的规则（R）

- [x] **R1 ⟨颜色⟩ 琥珀只给"保留"，加一个例外。** 问题：琥珀被用在进度条、筛选点、链接、"最佳"数值、小图条指示灯、卡片进度上。改法：琥珀（#DEA13F / #E8B45C）只出现在：保留的星、保留的描边、保留按钮的选中态；唯一例外是进度条前沿那一小段光（它是"显影"的隐喻）。其他一律改成墨色（ink）或白色。涉及条目：A5.4、A6.3、A8.2、A7.3、A2.6、M4.4、M5.2、M6.4、M7.6、M2.7。
- [x] **R2 ⟨颜色⟩ 四角星只表示"保留 / 待复查"。** 问题：五颗星当评分、"推荐"标签用星。改法：评分改成数字 + 一条 3 px 细条（`主体清晰度 56` 那种），不画星；"推荐 / 同组最佳"用文字小标签，不带星。涉及：A10.1、A8.3、M8.2、M6.3。
- [x] **R3 ⟨装饰⟩ 一个状态一种信号。** 问题：保留 = 星 + 描边 + 两圈光晕 + 星的光晕 + 横扫光。改法：保留 = 实心金星（20 dp / 20 px）+ 1 px 琥珀描边（55 %）；去掉格子外的光晕（Android `drawBehind` 两圈；桌面 `.tile.keep` 的 `0 12px 36px` 阴影）。改判那一刻的横扫光只保留桌面端 ≥ 200 px 宽的格子，手机上不放。待复查 = 空心星，不描边。淘汰 = 缩小 4 % + 透明度 0.62，不描边。
- [x] **R4 ⟨重复⟩ 同一个数字只出现一次。** 问题：计数、进度在顶栏 / 横幅 / 页签重复。改法：进度（已分析 / 总数、剩余时间）只在进度卡（横幅）；保留 / 待复查 / 淘汰的数量只在页签 / 筛选栏；顶栏只放项目名。
- [x] **R5 ⟨装饰⟩ 说明句不常驻。** 问题：解释性的句子一直占着位置。改法：操作提示只出现到第 3 次操作（已有 `hintUses` 机制），之后收进"?"；页面副标题、底部解释段一律删除或缩到一行 ≤ 24 个字。
- [x] **R6 ⟨节奏⟩ 入场错开的上限。** 问题：首页卡片、起始屏、设置分组、风格卡片都用 45 ms 错开 + 170/0.997 弹簧，16 项要 1.5 s 才站稳；弹层里面还在做入场。改法：错开 24 ms（桌面）/ 30 ms（Android），最多 8 项，之后的一起出现；总时长 ≤ 500 ms；底部弹层、菜单、对话框内部的内容不做入场（弹层本身已经在动）。
- [x] **R7 ⟨节奏⟩ 不弹跳。** 问题：保留星弹出用阻尼 0.39（Android）/ 15 damping（桌面，ζ ≈ 0.38），转 −110°。改法：所有弹簧阻尼比 ≥ 0.65；星的出现 = 缩放 0.6 → 1、透明 0 → 1，用 `tap` 弹簧（600 / 0.65），不转。
- [x] **R8 ⟨节奏⟩ 时长只用四档。** 问题：实际用到 140 / 200 / 260 / 300 / 500 / 620 / 700 / 750 / 760 / 950 / 1100 ms。改法：只用 160 / 320 / 600 / 900：悬停和颜色 160；菜单、弹层、页签切换、进度条 320；翻页、改判的光效、光点飞行 600；对焦（focus pull）、背景交叉淡入 900。
- [x] **R9 ⟨节奏⟩ 循环动效只给"正在工作的那一个"。** 问题：分析中每个未开始的格子都在扫光、每个进行中的都在呼吸。改法：未开始的格子静止（只有底色）；同一时刻只有正在处理的格子有一个动效（进度环）；进度条前沿的光是唯一允许一直在的循环。
- [x] **R10 ⟨层次⟩ 格子上的覆盖层最多两个。** 问题：110 dp 的格子上同时有格式标签、星、分数。改法：格子 < 160 dp（Android）/ < 180 px（桌面）时只显示记号（星）；格式标签（HDR / 实况 / RAW）只在大图、检查器、对比视图显示；分数只在"按评分排序"时显示在左下。
- [x] **R11 ⟨字号⟩ 字号阶梯七档、圆角五档、间距四的倍数。** 见第 4 节规则表。去掉所有 .5 的字号（12.5 / 13.5 / 14.5 / 10.5 / 11.5）。
- [x] **R12 ⟨颜色⟩ 调色板之外没有颜色。** 问题：桌面侧栏 logo 的蓝色投影（`rgba(60,80,200,.28)`）、准备页的米色相纸（`#f6f2ea`）、起始屏插画的蓝绿渐变、对比视图的 `#ffd98a` / `#ffe3a3`。改法：全部删除；插画用内置的示例照片。
- [x] **R13 ⟨层次⟩ 同一控件一种选中态。** 问题：保留 / 待复查 / 淘汰三个按钮在桌面检查器里是三种选中样式（琥珀淡底 + 琥珀边 / 线底 + 灰边 / 墨边），在单张、大图、Android 又各不同。改法：选中 = 实心：保留琥珀底 + `gleamInk` 字，待复查 / 淘汰墨色底 + 反白字；未选 = surface 底、无边框。高度：行内 44（Android）/ 30 px（桌面）；大图里是玻璃胶囊 46 dp。
- [x] **R14 ⟨对齐⟩ 页边一个数。** Android：页面内容、状态页签、照片墙都用 16 dp 边距（现在页签 16、墙 12，左边错 4 dp）。桌面：工作区内容 16 px，墙 16 px。

### A5 分析中

### 4.5 动效时长与弹簧

| 档 | 时长 / 弹簧 | 用途 |
|---|---|---|
| fast | 160 ms，ease-out | 悬停、颜色、透明度、菜单与气泡出现 |
| base | 320 ms，expo-out `cubic-bezier(.16,1,.3,1)` | 页签切换、弹层、对话框、进度条、翻页、模块切换 |
| slow | 600 ms，expo-out | 改判的光效（横扫、光圈）、光点飞行、淘汰退后 |
| develop | 900 ms，expo-out | 对焦（focus pull）、分析卡背景交叉淡入 |
| glide | spring 420 / ζ 0.976 | 布局重排、下划线、焦点框、小坞、分段胶囊、底栏宽度 |
| soft | spring 170 / ζ 0.997 | 入场（R6 的错开规则） |
| view | spring 230 / ζ 0.989 | 照片 ↔ 大图（进入和关闭都用它） |
| tap | spring 600 / ζ 0.65 | 按压反馈、星的出现（缩放 0.6 → 1，不旋转）、玻璃鼓起 |

规则：阻尼比不低于 0.65（不弹跳）；入场错开 24 / 30 ms、最多 8 项、总时长 ≤ 500 ms；弹层和菜单内部不做入场；循环动效只给正在工作的那一个元素；所有动效只动 transform / opacity（对焦允许 filter）。
