# aiwren 标识使用规范（一页版）

> 给不做设计的人看的。原则：用现成文件，别重画、别改色、别加效果。

## 1. 标识

- **含义**：一只戴焦糖棕翻边毛线帽的鹪鹩（wren）从画面底边冒头，呆毛从帽顶卷出，尖上挑着一颗琥珀色四角星芒。aiwren = AI + wren：鸟是 wren，星芒是 AI，也和惊鸿 FleetingGleam 应用的标志形同源。
- **版本**：
  - 标识：`svg/symbol.svg`
  - 横版组合：`svg/lockup.svg`
  - 竖版组合：`svg/stacked.svg`
  - 纯字样：`svg/wordmark.svg`
  - 头像：`svg/avatar.svg`
  - 小尺寸版：`svg/symbol-small*.svg`
- **字样**：aiwren 是用和小鸟同一线宽的圆头单线手工构造的，不是字体。请直接用文件，不要用任何字体打出来代替。

## 2. 留白

标识四周至少留出 **1 个眼睛直径**（在 256 的绘图网格里是 27 个单位，约等于标识宽度的 1/6）。留白跟着标识一起缩放，不用固定像素。

## 3. 最小尺寸

| 版本 | 屏幕 | 印刷 |
|---|---|---|
| 标识（标准版） | 48 px | 10 mm |
| 标识（小尺寸版 `symbol-small*`） | 16–47 px | 5–10 mm |
| 横版组合 | 宽 140 px | 宽 30 mm |
| 竖版组合 | 宽 72 px | 宽 16 mm |

小于 48 px 时（favicon、列表头像）一律换小尺寸版：线更粗、星芒更大、去掉眼神光。

## 4. 颜色

| 名称 | 用途 | HEX | RGB | CMYK（换算，需打样） |
|---|---|---|---|---|
| 墨 | 线条、眼睛、字样；深色底 | `#2A221D` | 42 34 29 | 0 19 31 84 |
| 米白 | 浅色底；深色版的脸 | `#FBF4EA` | 251 244 234 | 0 3 7 2 |
| 琥珀 | 星芒、嘴、i 的点（点睛色，只用在小面积上） | `#E8A043` | 232 160 67 | 0 31 71 9 |
| 焦糖棕 | 毛线帽 | `#B9824B` | 185 130 75 | 0 30 59 27 |

- **对比度**：墨/米白 14.3 : 1；琥珀/墨 7.1 : 1；焦糖棕/墨 4.7 : 1。
- **琥珀不能当文字色**：琥珀放在米白上只有 2.0 : 1，只能用作图形点缀，不要拿来写字。
- **Pantone**：没有官方对应色号，印刷前拿 Pantone Coated 色卡就近比对，以打样为准。

**可用的标识 / 底色组合**：

| 场景 | 用哪个文件 |
|---|---|
| 浅底（白、米白） | 彩色版 `symbol` / `lockup` |
| 深底（墨或接近黑） | 深色版 `*-dark`：米白脸、墨色眼睛、线略细 6 % |
| 单色印刷 | `*-black`，帽子变成墨色实心 |
| 单色印刷，深底反白 | `*-white` |
| 照片上 | 放在照片里平静的区域，或用带底板的 `avatar` / `app-icon` |

## 5. 字体（配套文字用）

- **英文标题**：Nunito（SIL OFL，可商用）。
- **中文与正文**：系统字体栈 `-apple-system, "PingFang SC", "Noto Sans SC", sans-serif`。
- **原则**：最多两套字族。配套字体只用于正文和标题，不能替代 aiwren 字样。

## 6. 不要这样做

- 不要拉伸、压扁、旋转标识。
- 不要改色，不要给帽子、星芒换成调色板以外的颜色。
- 不要加阴影、描边、渐变、发光。
- 不要拆开或重新排列组合版里的小鸟和字样，也不要改它们的大小比例。
- 不要在花哨的背景上直接放彩色版。
- 不要把小尺寸版放大使用。
- 不要再加腮红、尾巴、围巾、胸前羽毛、整块填满的身体，这些都是被否掉的方向。

## 7. 文件与联系

`docs/brand/avatar/wren/` 下各目录的内容：

| 目录 | 内容 |
|---|---|
| `final/` | 母版脚本 `make.py`（重跑 `python3 make.py` 生成全部 SVG）、片头 `intro.py`、`intro.mp4` 与 `intro-dark.mp4`；上一版在 `final/archive-v1/` |
| `brand-kit/svg/` | 全部矢量文件，包括 `favicon.svg`、`app-icon*.svg`、`maskable.svg`、`social-card.svg` |
| `brand-kit/png/` | 透明底 PNG 与头像 PNG；`avatar-1024.png` 用作 GitHub 头像，`social-card-1280x640.png` 用作仓库社交预览 |
| `brand-kit/web/` | 网页图标套装：favicon.ico/svg、apple-touch-icon、PWA 图标、`site.webmanifest`、`head-snippet.html` |
| `brand-kit/board/` | 展示板 `board.html`，`slides/` 下是每页 PNG |
| `brand-kit/build.py` | 重新导出整个标志包 |
