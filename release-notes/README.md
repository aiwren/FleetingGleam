# 更新说明

每个版本一个文件夹，名字就是版本号（`0.1.1/`），里面放：

- `zh-CN.md`：中文说明，必需。
- `en.md`：英文说明，可选；没有时英文界面也显示中文。
- 配图：WebP，宽 1200 像素左右（手机截图 720），每张 100 KB 以内。

发布工作流用 `.github/scripts/release-notes.sh` 把两份拼起来：中文在前，然后一行 `<!-- en -->`，再是英文；
图片的相对路径换成按版本标签固定的 `raw.githubusercontent.com` 地址。结果同时放进 GitHub Release 正文和 Mac 更新清单 `latest.json`，
两端应用在"设置 › 关于"里按界面语言显示其中一半。没有这个文件夹时退回 CHANGELOG.md 里该版本的那一节。

## 应用认的写法

应用只渲染下面几种，别的 Markdown 会原样显示成文字：

```markdown
开头一段概述。

### 小标题

![图片说明](配图.webp)

一段正文，可以有 **加粗**。

- 列表项
- 列表项
```

- 图片单独占一行，地址写相对路径。
- 每个小标题配一张图就够了，不要求每节都有。
- 截图里不要出现真实的个人照片：Mac 用 `?mock` 预览里的示例项目，安卓用模拟器上的示例照片。
